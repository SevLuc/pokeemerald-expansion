# Encounter Candidate Pool (by type)

Working list of Pokemon approved to appear as wild encounters, built type by
type. Selections come from the full 9-gen National Dex pool; the player picks
per type which species are in the game. Route/area placement is assigned later.

Status legend: **Selected** = approved into the pool. Not-listed species from
the candidate pool were reviewed and cut.

**Evolution-item access (DONE):** all evolution items are sold by the Celadon
Dept. Store 4F clerk. Stones (Fire/Thunder/Water/Leaf already there + Ice, Sun,
Moon, Shiny, Dusk, Dawn, Oval) and trade/held-item evo items (Linking Cord,
Metal Coat, King's Rock, Dragon Scale, Protector, Electirizer, Magmarizer,
Up-Grade, Dubious Disc, Reaper Cloth, Prism Scale, Razor Fang, Razor Claw). All
priced at the 3000 stone tier. So no trade-evo or item-evo mon is stuck.

**Friendship evos:** caught Pokemon start at max friendship (255), so
friendship evolutions are immediate. Eevee also gains stone paths (Sun→Espeon,
Moon→Umbreon, Shiny→Sylveon) as a backup.
